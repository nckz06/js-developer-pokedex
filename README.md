# Trilha JS Developer - Pokedex

Com o intuito de entender a aplicação do JavaScript em relação ao Desenvolvimento Web, foi construído uma pokedex com a utilização das linguagens HTML, CSS e o próprio JavaScript, responsável por realizar a conexão entre a página construida e a API PokeAPI, que traz e, consequentemente, alimenta o conteúdo da página. Com o JavaScript foi possível manipular as informações fornecidas pela API de forma dinâmica, diminuindo a necessidade de adição de conteúdo de forma manual e simplificando a visualização dessas informações durante a navegação dentro da página

[Veja aqui o resultado final do projeto](https://nckz06.github.io/js-developer-pokedex/)
